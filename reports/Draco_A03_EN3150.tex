\section{Introduction}
This assignment investigates image classification under strict edge-computing constraints. The work uses the UCI DeFungi microscopic image dataset and compares two custom convolutional neural networks with two lightweight pre-trained architectures. The central engineering question is not accuracy alone, but how much accuracy is obtained for a given parameter count, checkpoint size, and arithmetic cost.

All final numerical values in this report are taken from the corrected Stage-2 artifacts. Existing Model A, Model B, MobileNetV2, and ShuffleNetV2 checkpoints were preserved; only the missing controlled optimizer-comparison experiment was newly trained. Computational cost is reported using one common convention: Conv2d and Linear multiply-accumulate operations (MACs) for a $3\times64\times64$ input. Batch normalization, activation, pooling, residual additions, concatenation, channel shuffle, softmax, and data movement are excluded. FLOPs are reported as $2\times$ MACs. These are calculated operation counts, not latency measurements.

\section{Task 2: Custom Architecture Design}
\subsection{Model A: Standard CNN}
Model A interleaves standard $3\times3$ convolutions with BatchNorm, ReLU, and $2\times2$ max-pooling. Channel width grows from 32 to 256 while spatial resolution is reduced from $64\times64$ to $4\times4$. The classifier is $4096\rightarrow512\rightarrow128\rightarrow5$ with dropout.

The exact trainable parameter count is \textbf{2,553,349}. The corrected calculation is:
\begin{align*}
\text{feature extractor} &= 389,376,\\
\text{classifier} &= 2,163,973,\\
\text{total} &= 2,553,349.
\end{align*}
ReLU is hardware-friendly because it is piecewise linear and avoids transcendental operations such as exponentials. This is advantageous on resource-constrained processors and common integer inference kernels.

\subsection{Model B: Lightweight depthwise-separable CNN}
Model B contains a small standard stem followed by six depthwise-separable convolution blocks, Global Average Pooling, dropout, and a $128\rightarrow5$ classifier. Each block factorizes a standard convolution into a depthwise $3\times3$ operation and a pointwise $1\times1$ projection.

For a standard convolution with $M$ input channels, $N$ output channels, kernel size $D_K$, and output spatial size $D_G\times D_G$:
\begin{equation}
\mathrm{MACs}_{\mathrm{std}}=D_K^2MN D_G^2.
\end{equation}
For depthwise separable convolution:
\begin{equation}
\mathrm{MACs}_{\mathrm{sep}}=D_K^2M D_G^2 + MN D_G^2.
\end{equation}
The ratio is
\begin{equation}
\frac{\mathrm{MACs}_{\mathrm{sep}}}{\mathrm{MACs}_{\mathrm{std}}}=\frac{1}{N}+\frac{1}{D_K^2}.
\end{equation}
For $3\times3$ kernels, this yields a substantial per-block reduction.

The exact trainable parameter count of Model B is \textbf{37,957}, which is 62.04\% below the assignment ceiling of 100,000 parameters. Relative to Model A, Model B uses \textbf{98.51\% fewer parameters}, or approximately \textbf{67.27$\times$ fewer}. ReLU6 is used as a bounded piecewise-linear activation; its bounded output range can be useful for quantization, while still avoiding expensive transcendental evaluation.

The compared optimizers were standard SGD, SGD with momentum, and Adam.

\begin{figure}[H]

\caption{Controlled Task-3 optimizer comparison. Momentum accelerates SGD convergence and improves the final metrics, while Adam provides the strongest overall validation and test performance in this experiment.}

Momentum updates the running direction using a velocity term. A common form is
\begin{align*}
v_t &= \mu v_{t-1}+g_t,\\
\theta_{t+1} &= \theta_t-\eta v_t,
\end{align*}
where $\mu$ is the momentum coefficient. In the experiment, SGD with momentum reached 66.28\% validation accuracy by epoch 2 and peaked at 70.09\% by epoch 12, while standard SGD reached a lower 67.01\% peak only at epoch 19. Thus, momentum provided faster convergence and better final performance under the controlled setup. Adam was selected because it obtained the best validation accuracy, test accuracy, and macro F1.

\subsection{Advantages and limitations of Model B}
\textbf{Advantages:}
\begin{itemize}[nosep]
\item Strictly satisfies the sub-100k trainable-parameter requirement.
\item Very small checkpoint and low calculated arithmetic cost.
\item Simple depthwise-separable building blocks and global average pooling reduce dense-layer overhead.
\item Does not depend on ImageNet pre-training.
\end{itemize}

\textbf{Limitations:}
\begin{itemize}[nosep]
\item Lower test accuracy than both fine-tuned SOTA models.
\item Lower representational capacity because of the aggressive parameter budget.
\item Training from scratch must learn both low-level and task-specific features from the comparatively small DeFungi dataset.
\item H2 remains the most difficult major class, with recall 0.4387 in the main Model-B run.
\end{itemize}

\subsection{Advantages and limitations of pre-trained SOTA models}
\textbf{Advantages:}
\begin{itemize}[nosep]
\item ImageNet pre-training supplies reusable low-level and mid-level visual features.
\item Both SOTA models substantially improve test accuracy and macro F1.
\item MobileNetV2 gives the highest accuracy; ShuffleNetV2 offers a strong middle point between accuracy and resource cost.
\end{itemize}

\textbf{Limitations:}
\begin{itemize}[nosep]
\item Much larger parameter and storage footprints than Model B.
\item Higher calculated arithmetic cost.
\item Pre-training creates a domain-transfer dependency: ImageNet features are useful, but the source domain differs from microscopic fungi.
\item Actual edge-device feasibility still depends on peak activation memory, operator support, quantization, and measured latency.
\end{itemize}

\subsection{Deployment recommendations}
\begin{itemize}
\item \textbf{Strictest memory/compute budget:} choose Model B. It is the only custom sub-100k model and has the lowest MAC count and checkpoint size. Before claiming deployment on a specific MCU, perform quantization, peak-RAM profiling, and an on-device latency test.
\item \textbf{Balanced accuracy and efficiency:} choose ShuffleNetV2 1.0x. It improves accuracy by 13.33 percentage points over Model B with substantially less storage and MAC cost than MobileNetV2.
\item \textbf{Accuracy-first edge deployment:} choose MobileNetV2. It reaches 86.31\% test accuracy and macro F1 0.8805, at the cost of the largest checkpoint and highest MAC count among the three final candidates.
\end{itemize}

\section{Overall Conclusion}
The experiments demonstrate that depthwise-separable design can reduce resource cost dramatically without necessarily reducing accuracy. Model B is 98.51\% smaller in parameter count than Model A, requires about 7.26 M Conv/Linear MACs, and slightly improves both test accuracy and macro F1. However, transfer learning changes the accuracy-efficiency frontier: MobileNetV2 reaches 86.31\% test accuracy and ShuffleNetV2 reaches 83.76\%, versus 70.43\% for Model B.

The correct engineering choice therefore depends on the deployment constraint. Model B is the strongest candidate when model capacity must remain extremely small; ShuffleNetV2 is the most attractive compromise when moderate resources are available; and MobileNetV2 is preferred when accuracy dominates the resource budget. These conclusions are based on verified checkpoint sizes, measured test metrics, and consistently calculated MAC counts. Device-specific latency and peak runtime RAM remain future deployment measurements rather than assumed results.
