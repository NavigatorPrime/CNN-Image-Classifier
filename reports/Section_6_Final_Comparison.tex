\subsection{Engineering Recommendation}
\begin{itemize}[leftmargin=*]
\item \textbf{Strictest parameter/storage/compute budget: Model B.} Its depthwise-separable design is trained from scratch and contains only \ModelBParams{} parameters. Deployment still requires peak-RAM and latency measurement.
\item \textbf{Balanced option: ShuffleNetV2 1.0x.} It reaches \ShuffleAccuracy\% accuracy while using fewer parameters, storage, and MACs than MobileNetV2.
\item \textbf{Accuracy-first option: MobileNetV2.} It reaches \MobileAccuracy\% accuracy and macro F1 \MobileFOne, with the largest arithmetic cost of the three.
\end{itemize}

\section{Conclusion}
The corrected experiments show a clear three-way trade-off. Model B minimizes resource demand, ShuffleNetV2 provides the middle point, and MobileNetV2 maximizes accuracy. The appropriate model depends on measured target-platform constraints rather than checkpoint size alone.
